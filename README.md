## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`, `about.html`, `contact.html`, and `styles.css` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Test the temporary GitHub Pages URL before changing GoDaddy DNS.

## Custom domain
When ready, set the GitHub Pages custom domain to:
`www.maroonsbackstageboosters.org`

Do not change MX, SPF, DKIM, or DMARC records when moving the website.
